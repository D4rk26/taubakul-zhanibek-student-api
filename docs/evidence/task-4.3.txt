## Explanation
- Error: in StudentControllerTest.infoContainsAuthorName the expected author was changed to
  "Zhanibek Taubakul", while /api/info returns "Taubakul Zhanibek Nurlanuly" (commit a259ca9).
- Where it is visible: Test stage console — `StudentControllerTest > infoContainsAuthorName() FAILED`,
  `java.lang.AssertionError at StudentControllerTest.java:245`, `22 tests completed, 1 failed`,
  `BUILD FAILED`, `ERROR: script returned exit code 1`; the JUnit report (published in post/always)
  shows the exact message: JSON path "$.author" expected:<Zhanibek Taubakul> but was:<Taubakul Zhanibek
  Nurlanuly>.
- Effect: `./gradlew test` exited with code 1 -> the sh step failed -> the Test stage failed -> Jenkins
  skipped "Docker Build" and "Verify" (console: "Stage ... skipped due to earlier failure(s)"; the stage
  API reports them as FAILED but they contain no shell step) -> build #1 FAILURE, no image was built.
- Fix: restored the correct expected value in a separate commit (38dc247), verified locally with
  ./gradlew clean build, pushed; Jenkins picked up the commit and build #2 passed all stages (22/22).
- The branch is not merged into main: it stays as proof; main was never broken.
