## > versus >>
$ echo "first line" > /tmp/taubakul_redirect_demo.txt; cat /tmp/taubakul_redirect_demo.txt
first line

$ echo "second line (appended with >>)" >> /tmp/taubakul_redirect_demo.txt; cat /tmp/taubakul_redirect_demo.txt
first line
second line (appended with >>)

$ echo "third line (overwrite with >)" > /tmp/taubakul_redirect_demo.txt; cat /tmp/taubakul_redirect_demo.txt
third line (overwrite with >)

$ rm /tmp/taubakul_redirect_demo.txt && ls /tmp/taubakul_redirect_demo.txt
ls: /tmp/taubakul_redirect_demo.txt: No such file or directory

## Explanation: > vs >>
>  redirects output to a file and OVERWRITES it (the file is truncated or created first).
>> redirects output to a file and APPENDS to the end (the file is created if missing).
The system report script uses `tee -a` (the tee equivalent of >>) so every run is added to the log
instead of replacing previous runs.
